# financial-client-data-analysis
Conducted EDA on a bank's client-level financial dataset (deposits, credit, loans, superannuation, risk weighting) to uncover asset-liability and risk patterns.
This repository presents the Exploratory Data Analysis (EDA) of a Banking Dataset containing information about customers and their financial behavior. The dataset includes a range of features that can be analyzed to gain insights into customer demographics, banking products, financial patterns, and risk factors.
